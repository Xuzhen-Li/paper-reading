# Claim and evidence

Keep three layers in the prose. Do not stamp labels.

1. What the authors report
2. How far the data directly go
3. What this note infers

The note's inference must not be written in the authors' voice. If prose and a figure/table disagree, record both values and their sources.

## Verb table

| Evidence | Allowed | Overclaim |
|----------|---------|-----------|
| Number or topology printed in Results/figure | 报告、给出、测得、恢复出 | 证明了机制 |
| Association, tree, model output | 与……一致、支持、提示、相关 | 导致、决定、证实 |
| Authors' story | 作者提出、作者推测、可解释为 | 已揭示机制 |
| This note | 这更像……、一种可能解释是…… | as if the paper concluded it |
| Missing or too thin | 原文未说明、尚不能判断 | textbook fill-in |

`导致` / `必要` need a design that supports causation or ablation. Do not copy `first` / `novel` as fact.

If a precise number cannot be found in the PDF or extract, delete it, hedge, or write `原文未说明`. Never invent.
